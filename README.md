# Browser context test

Standalone browser viewport and SHA-256 comparison experiment. Open in a Custom Tab, wait three seconds, copy the comparison link, and open it in external Chrome.

The hash includes only the displayed browser inputs. The baseline hash travels in the URL fragment; the page does not use cookies, localStorage, analytics, or a collection endpoint. A mismatch is a change in inputs, not proof of browser type. Early, timed, resize, and manual samples remain available through Copy results.
